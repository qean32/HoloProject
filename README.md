### HOLO PROJECT

Терминальное приложение для Windows: хранит и запускает `.bat`-команды,
показывает список с поиском, ведёт лог и меню.

<img src="https://github.com/qean32/qean32/blob/main/img/image_holo.png" />

## Возможности

- Хранение `.bat`-команд в личном каталоге и запуск по имени.
- Полноэкранный список команд: стрелки, `PgUp`/`PgDn`, `Home`/`End`,
  фильтр по вводу, подсветка выбранной строки.
- Подтверждение удаления и диалог создания команды.
- Лог событий с ротацией при 1 МБ (`log.asc` → `log.asc.1`).
- Технический вывод событий по команде `logger`.
- Очистка экрана через ANSI, без запуска `cmd /c cls`.
- Автоматический перенос старых данных из `%TEMP%\holoproject`.

## Быстрый старт

Требования: Windows 10+, Go 1.25 или новее для сборки.

```powershell
go build -ldflags "-X main.version=0.1.0" -o holoproject.exe .
.\holoproject.exe
```

Флаги:

```text
--root <каталог>   каталог данных (по умолчанию %LOCALAPPDATA%\holoproject)
--version          версия, ОС/архитектура и версия Go
--list             показать команды и выйти
--run "<команда>"  выполнить одну команду без TUI
--yes              подтвердить удаление в --run
--help             справка
```

### Без TUI

```powershell
holoproject --list
holoproject --run "bat hello p/echo hello"
holoproject --run "run hello"
holoproject --run "rbat hello" --yes
```

`--run` выполняет только неинтерактивные команды. Для `list`, `menu` и
диалогов возвращается код `2`; `rbat` без `--yes` тоже считается
интерактивным. Ошибки — код `1`.

Каталог можно задать и переменной `HOLO_ROOT`; `--root` имеет приоритет.

## Команды

| Команда | Назначение |
|---|---|
| `help` | справка |
| `menu` | главное меню |
| `list` | список сохранённых `.bat` |
| `run <имя>` | выполнить `.bat` |
| `bat <имя> p/<команда>` | создать `.bat` |
| `rbat <имя>` | удалить `.bat` с подтверждением |
| `clear` | очистить экран |
| `clog` | очистить лог |
| `log` | открыть лог |
| `logger` | включить/выключить технический вывод |
| `drop` | удалить все данные приложения |
| `stop` | выход |

```text
bat hello p/echo hello
run hello
rbat hello
```

Синтаксис payload: `p/<команда>` или `-p:<команда>`. Пароль для будущих
криптокоманд: `pass/<пароль>` или `-pass:<пароль>`. Криптокоманды
(`crypto`, `ecrypto`, `gkey`, `gmaster`) пока не реализованы и скрыты
из справки и меню.

## Управление списком

| Клавиши | Действие |
|---|---|
| `↑` / `↓` | выбор |
| `PgUp` / `PgDn`, `Home` / `End` | прокрутка и края |
| ввод символов | фильтр по имени |
| `Backspace` | удалить символ фильтра |
| `Enter` | выбрать |
| `Esc` | сбросить фильтр, затем выйти |
| `Ctrl+C` | выйти из списка |

## Где лежат данные

`%LOCALAPPDATA%\holoproject`:

```text
holoproject/
├── cmd/       # сохранённые .bat
└── log.asc    # лог событий
```

Старый каталог `%TEMP%\holoproject` переносится при первом запуске.
`drop` удаляет каталог и создаёт его заново. При явном `--root` или
`HOLO_ROOT` миграция не выполняется.

## Ограничения

- Приложение только для Windows.
- `.bat`-команды запускаются через `cmd /C`; интерактивный ввод в дочернюю
  команду не пробрасывается.
- Криптокоманды пока являются заглушками.
